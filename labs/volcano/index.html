Step 1 · Plan and build

Build the volcano alert

The problem (book)

Owais is studying to be a physical volcanologist. He is writing about how scientists track volcanic activity and wants a model to show his class. Scientists use colours for how active a volcano is:

Green: no activityYellow: some signsOrange: minor emissionsRed: will erupt soon
Brainstorm (book): how can a model give a signal about the volcano?

Build it step by step. For each step, find the right part in the box (some are traps!), then answer the question. Every mistake is counted.

    Step 3 · Program (book)

    Program the volcano alert

    How to read it: Start → Motor this way → Motor power 3 → Wait for the tilt sensor (the volcano shakes) → Motor on for 2 seconds → Wait for the tilt sensor again → Motor that way → Motor on for a random time 🎲. The needle swings, then stops on a colour.

    Click a block to add it, click a block in your program to remove it. Choose the input in the orange or blue box.
