Lesson 1 · Meet your microcontroller

Raspberry Pi Pico

The Pico is a printed circuit board (PCB) that gives power, ground and signal connections. It is a microcontroller: the "brain" that stores your code and tells sensors, motors and lights what to do.

    Lesson 4

    The Servo Motor

    Wire a servo motor to the Pico through the shield, then write MicroPython that sends angle commands so it sweeps back and forth.

    Vocabulary

    Servo motorA motor that turns to an exact angle (0° to 180°) when it gets a command.
    ShieldAn extension board: the Pico plugs in and its GPIO pins come out on labelled terminals.
    PWMPulse Width Modulation: short on–off pulses. The pulse length (0.5–2.5 ms, 50 times a second) tells the servo which angle to hold.
    ModuleA Python file with ready-made code you import, like myservo.py.

    The shield and the servo (book)

    When the Pico is on the shield, its GPIO pins come out on labelled terminals. At the bottom right, grouped G / V / S pins (Ground, Voltage, Signal) make 3-wire parts like the servo and the PIR sensor easy to plug in.

    A servo has 3 wires: brown = ground, red = power, yellow (orange) = signal.

    Lesson 5

    Controlling an Output with an Input

    Use an input (a photoresistor) to control an output (an LED). The more light falls on the photoresistor, the brighter the LED shines.

    Vocabulary

    PhotoresistorA resistor whose resistance decreases as the amount of light hitting it increases.
    ResistanceThe opposition to the flow of electrical current, measured in ohms.
    BrightnessThe amount of visible light given out by the LED, controlled by voltage or current.
    ResistorA circuit component that limits or controls the flow of electric current.

    Input + output (book)

    In Lesson 3 we read an input (the temperature sensor). In Lesson 4 we controlled an output (the servo). Now we combine both: the photoresistor reading decides how bright the LED is.

    The Pico reads the photoresistor with its ADC (analog-to-digital converter) as a number from 0 to 65535, and dims the LED with PWM: switching it on and off very fast. The longer it stays on in each cycle (the duty cycle), the brighter it looks.

    1 · Insert the photoresistor and the LED

    Book step 1: both parts have stiff legs, so they plug straight into the breadboard next to the Pico pins. No jumper wires are needed. The LED's long leg is + and its short leg is −.

    Photoresistorlong leg → GP26 · other leg → GND
    LEDlong leg → GP16 · short leg → GND

    For each leg, click the Pico pin it goes next to.
